## 🎯 Deploy to Vercel in 4 Simple Steps

### STEP 1: Initialize Git Repository

```bash
cd "d:\Dooti\VS Code Files 2\Campus Recovery Hub\Campus-Recovery-Hub"

git init
git add .
git commit -m "feat: Initial commit - Campus Recovery Hub v2.0.0"
```

### STEP 2: Install Vercel CLI

Open PowerShell/Terminal and run:
```bash
npm install -g vercel
```

Verify:
```bash
vercel --version
```

### STEP 3: Login to Vercel

```bash
vercel login
```

Browser will open - follow the login prompts

### STEP 4: Deploy!

```bash
cd "d:\Dooti\VS Code Files 2\Campus Recovery Hub\Campus-Recovery-Hub"
vercel
```

Follow the interactive setup:
- ✅ Confirm you want to deploy
- ✅ Select Python framework
- ✅ Keep default settings
- ✅ Deploy!

## 🔐 Post-Deployment Configuration

After deployment succeeds, you'll get a URL like: `https://campus-recovery-hub.vercel.app`

### Add Environment Variables (IMPORTANT!)

In your terminal:
```bash
vercel env add SECRET_KEY
# Paste: (generate with: python -c "import secrets; print(secrets.token_urlsafe(32))")

vercel env add FLASK_ENV
# Paste: production

vercel env add FLASK_DEBUG
# Paste: False

vercel env add MAIL_SERVER
# Paste: smtp.gmail.com

vercel env add MAIL_PORT
# Paste: 587

vercel env add MAIL_USE_TLS
# Paste: True

vercel env add MAIL_USERNAME
# Paste: your-email@gmail.com

vercel env add MAIL_PASSWORD
# Paste: your-app-password

vercel env add MAIL_DEFAULT_SENDER
# Paste: noreply@campusrecoveryhub.com
```

### Redeploy with Environment Variables

```bash
vercel --prod
```
